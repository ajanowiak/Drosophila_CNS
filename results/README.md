The `results/` directory contains results generated by the data analysis code found in `src/`.

Its layout mirrors `src/py/` and `src/snakemake/`: one top-level directory
per pipeline stage (`prepare_data`, `train_full_models`, `shap_importance`,
`first_logit_model`, `second_logit_model`), each subdivided by script/rule,
each with its own `figures/` subdirectory for plots. For example:

```
results/
├── prepare_data/
│   └── <filtering_mode>/hrs<window>/                 (motif_enrichment.csv, y_<tissue>.csv, ...)
├── train_full_models/
│   ├── train_time_agnostic/    (models/, cv_aucroc_summary/, figures/)
│   ├── train_time_specific/    (models/, cv_aucroc_summary/, roc_results/, figures/)
│   ├── combined_roc_plot/      (figures/)
│   └── compare_bar_plots/      (figures/)
├── shap_importance/
│   └── shap_analysis/          (tables/, figures/)
├── first_logit_model/
│   ├── regression_coefs/       (tables/, figures/)
│   └── logit_regression_aucroc/  (tables/)
└── second_logit_model/
    └── logit_regression_significant_features/  (tables/, figures/)
```

Only `figures/` subdirectories (wherever nested) are tracked in git; every
other file under `results/` is generated output and gitignored - see
`.gitignore`.
